# Alturas initial-HTML pilot — September 19, 2026

The existing metadata release `6c11ed3` was pushed and verified in production on
September 19. Its root + 11 cultivar URLs, query aliases, 404s, robots and sitemap
passed `scripts/check-seo.py` with browser and Googlebot user agents.
Google Search Console processed the Explorer sitemap successfully and discovered
12 pages the same day. This establishes discovery, not indexing of all 12 pages.
Alturas's stored URL inspection still reports it indexed; recrawl is a separate step.

## Pilot boundary

Only English Alturas direct arrivals receive initial cultivar content from the
server. `app/page.tsx` imports the existing public JSON and passes it into the
existing Explorer/detail components as initial state. The rendered descriptions,
recommendations, metrics, images and charts use the original components and data.
No duplicated prose or hidden crawler-only content. Other cultivars and explicit
non-English query links retain the existing loading behavior. Language selection
continues to load the original translations.

Cultivar selectors on desktop and mobile now use ordinary anchors pointing at the
existing cultivar paths. Plain clicks keep the original replaceState/transition
behavior; modified clicks retain native browser link behavior. No new routes,
styles, dependencies, contact API, or data edits.
